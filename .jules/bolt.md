## 2023-10-25 - LangChain/LangGraph Caching inside Node Functions
**Learning:** LangChain objects like `ChatGroq` and `ChatPromptTemplate` should not be instantiated repeatedly on every turn inside LangGraph node functions (`services/graph/nodes.py`), as it creates significant performance overhead (e.g. 6.7 seconds for 100 instantiations vs 200 ms with cache). However, defining them as module-level global variables causes import-time Pydantic validation errors (like missing environment variables, which breaks dependency overrides during testing).
**Action:** Always use `@lru_cache` decorators on getter functions (`get_llm()`, `get_prompt()`) to cache LLM client instances and prompt templates. This ensures they are instantiated exactly once per process while deferring Pydantic validation until execution.
